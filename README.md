# Live2D Studio Google Sheets prototype

`package.json`이 있는 이 폴더를 VS Code에서 연 뒤 터미널에서 실행하세요.

```powershell
npm.cmd install
npm.cmd run dev
```

브라우저: http://localhost:5173

Google Sheets CSV에서 닉네임과 Drive 폴더 URL을 읽어 목록에 표시합니다. 현재 단계에서는 폴더 링크만 열 수 있고, 실제 Cubism 모델 렌더링은 연결되어 있지 않습니다.
